STARTING THE BACKEND:

Run from -->  ./EchoLogz/:
```bash
uvicorn backend.main:app --reload
```

----------------------------

STARTING THE FRONTEND:

Run from -- > ./EchoLogz/frontend-react/: 

> **Requires pnpm installed globally (outside your echologz env):**
> `npm install -g pnpm`


```bash
pnpm install
pnpm run dev
```
